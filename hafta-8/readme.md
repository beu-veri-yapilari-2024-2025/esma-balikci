# AVL Ağaçları (C#)

Bu proje, **AVL Ağacı (Adelson-Velsky and Landis Tree)** veri yapısının C# dili ile gerçekleştirilmiş bir **konsol uygulaması**dır. Projede ekleme, silme, arama ve listeleme işlemleri yapılırken ağacın dengesi otomatik olarak korunur.

## 📌 Proje Özellikleri
- AVL ağacına **ekleme (Insert)**
- AVL ağacından **silme (Delete)**
- **Arama (Search)** işlemi
- **In-order** dolaşma ile listeleme
- Sağ ve sol rotasyonlar ile **denge koruma**
- Menü tabanlı kullanıcı etkileşimi (Console UI)

## 🧠 Kullanılan Veri Yapıları
- **Node** sınıfı (Düğüm)
- **AVLTree** sınıfı
- Özyinelemeli (recursive) metotlar

## 🛠 Kullanılan Teknolojiler
- C#
- .NET Console Application

## ▶️ Program Menüsü
Uygulama çalıştırıldığında aşağıdaki seçenekler sunulur:
